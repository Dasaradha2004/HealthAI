# Optional training data

Place `ckd.csv` and/or `diabetes.csv` here to use local data instead of generated
demo rows. CSVs must include the clinical feature columns used by the API and a
binary target column named `target`, `class`, `classification`, or `Outcome`.
Accepted target labels include 0/1, positive/negative, and ckd/notckd. The
included generated datasets are synthetic and are not suitable for medical use.
